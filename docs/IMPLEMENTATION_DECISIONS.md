# Implementation decisions

Every place where this implementation differs from the reconstruction plan (`docs/RECONSTRUCTION_PLAN.md`), and every choice that the plan or the sources leave open and the code had to make, is listed here. Code comments, tests and result files cite these entries by ID (for example W6, M9, B3-10). Plan references (§, OQ, AM, T, D) resolve in `docs/RECONSTRUCTION_PLAN.md`; AM numbers are in its appendix.

Status values:
- **recorded**: a choice that is written down.
- **open question**: a point that the sources do not settle. The default in use is stated in the entry.
- **in use (AM…)**: a default of this implementation that is recorded as a plan amendment.

Tags (plan §0): **[EVIDENCE]** stated in the papers; **[INFERRED]** derived from published numbers; **[INVENTED]** / **[INVENTED-CALIBRATED]** no paper support (synthetic stand-in only); **[OPEN]** unspecified in the sources, a labelled default is in use.

Some IDs occur in two sections (E1–E5 and T1–T3 under "Environment" / "Float comparisons", and again E1–E10 and T1–T19 under the LOO and A15–A18 sections). A citation names the step or section where it matters.

## Float comparisons (steps A2, A4, A6)

| # | What | Why | Plan reference | Status |
|---|---|---|---|---|
| T1 | Two WC, HAC or SP scores within an absolute tolerance of 1e-9 are treated as tied (and so is feature 12, through f_HAC) | With exact float equality true ties are decided by rounding noise and are not logged: WC 2×0.3 vs 3×0.2 gives 0.12 vs 0.12000000000000002; 6962 of the 8385 exact SP ties with N ≤ 130 are missed. 1e-9 is far below any real score gap (about 4e-8 on a 0.01 grid at N = 1000). A numeric safeguard, not a modelling choice. Alternative: exact rational arithmetic on the raw integer answers | §8 OQ8 ("deterministic canonical order, logged"); AM3 | open question (AM3) |
| T2 | Features 16/17 compare r.c with AvgC and r.ps[v] with AvgPSV with the same tolerance: a value within 1e-9 of the average counts as equal to it | Without it the feature value depends on the order of the responses (the same 20 responses give 3/20 or 10/20), and identical responses give 1.0 instead of 0 for 30 values of N between 4 and 130 | §3.3 rows 16–17, OQ13; AM9 | open question (AM9) |
| T3 | The tolerance is not used for MR, a_max, a_min, the DA counters, the OQ8b support comparison or SG_B_Amax | These compare integer vote counts or labels (supports k/\|R\| with one common \|R\|), where exact comparison is correct | §3.1, §3.2 | recorded |
